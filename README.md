# Japanese for Scriba / 日本語

Scriba (プラグイン駆動の Markdown エディター) に **日本語インターフェース** を追加するプラグインです。

> **Note:** This repository is a standalone plugin. It is **not** bundled with Scriba — install it
> separately if you want it.
>
> **注記：** このリポジトリは独立したプラグインです。Scriba 本体には**同梱されていません**。
> 使う場合は別途インストールしてください。

---

## 機能

- UI 全体の日本語化（298 キー、コア辞書と完全一致）
- 「設定 → 外観 → 言語」に「日本語」が追加される
- コマンドパレットから「日本語に切り替える」を実行できる
- プラグイン自身の文字列も 3 言語（日本語 / English / 简体中文）に対応

## インストール

### 方法 1: プラグインマーケットプレイスから（推奨）

1. Scriba で **プラグインマネージャー**（タイトルバーのプラグインアイコン）を開く
2. **探す** タブで `japanese` または `日本語` を検索
3. **インストール** をクリック

> マーケットプレイスは GitHub のトピック `scriba-plugin` で検索しています。このリポジトリに
> そのトピックが付いている必要があります。

### 方法 2: 手動

プラグインフォルダー（Scriba の **設定 → このアプリについて → プラグイン** のパス）に
このリポジトリをフォルダーごとコピーし、プラグインを再読み込みしてください。

```
<userData>/plugins/japanese/
├── manifest.json
└── index.js
```

## 使い方

インストール後、プラグインを有効にすると:

1. **設定 → 外観 → 言語** に `日本語` が表示されます
2. 選択すると即座に切り替わります

または `Ctrl/Cmd + P` でコマンドパレットを開き、`日本語` と入力して実行します。

## 翻訳の完全性

コア辞書（`en-US`、298 キー）と 1:1 で対応しています。

| 項目 | 状態 |
| --- | --- |
| キー数 | 298 / 298 |
| 欠落キー | 0 |
| 余剰キー | 0 |
| プレースホルダー（`{name}` など）の一致 | 全キー一致 |

不足しているキーがあっても、実行時には英語にフォールバックするため、部分翻訳でも
動作します（穴が空くだけです）。

## 既知の制限

**ネイティブメニューは日本語になりません。**

アプリケーションメニュー（File / Edit / View …）はメインプロセスが描画し、メインプロセスは
アプリに組み込まれた言語辞書しか知りません。プラグインが追加した言語はレンダラー側にのみ
存在するため、メニューは英語のままになります。

これは現在の API の制限です。メニューを含めた完全な日本語化には、アプリ本体への
言語の組み込みが必要です。

その他の制限:

- フォントは OS に依存します。日本語フォントがインストールされている必要があります
  （Windows / macOS では標準で入っています）
- 数値や日付の書式は翻訳対象外です

## カスタマイズ

`index.js` の `MESSAGES` を編集すると訳文を変更できます。他の言語のプラグインを作る場合は、
このリポジトリをフォークして以下を変更してください:

1. `manifest.json` の `id` / `name` / `description`
2. `index.js` の `registerLanguage({ id, name, translations })`
3. `MESSAGES` の中身

`id` は BCP-47 タグ（`ja-JP`, `fr-FR`, `de-DE` …）にしてください。設定画面と
`<html lang>` がこの値をそのまま使用します。

プラグイン自身の UI 文字列は `PLUGIN_MESSAGES` にあり、`registerTranslations` で登録します。

## 開発

プラグインはサンドボックスなしでアプリと同じ権限で動作します。`require` は使えないため、
すべてのコードは `index.js` に含める必要があります。

```js
module.exports.activate = function (scriba) {
  scriba.i18n.registerLanguage({
    id: 'ja-JP',
    name: '日本語',
    translations: MESSAGES
  })
}
```
